IoT prototype

從 FPGA 核心走到實際資料鏈。

Raspberry Pi 4 負責相機擷取、H.264 編碼與封包化；Arty A7-100T 執行 keyed-SPI AES-GCM-256 保護；PC 作為地面站接收並驗證資料。ML-KEM-768 與 HKDF-SHA256 用於 Session Key 衍生。

IP capabilities

為安全封包而設計的可整合模組。

01

AES / GCTR

支援 AES-GCM-128/192/256，處理加密、解密與 Counter mode 資料流。

02

GHASH

在 GF(2^128) 上計算 AAD 與 Ciphertext 的認證雜湊。

03

UART / SPI

透過既有的封包與介面包裝，連結 FPGA、MCU、Raspberry Pi 與 PC。

04

AUTH_FAIL

Tag 驗證失敗時拒絕封包，不在完整性確認前釋出明文。
