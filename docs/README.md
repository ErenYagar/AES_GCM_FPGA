## Local preview

Open `index.html` directly in a browser, or serve this folder with any static HTTP server. The language button switches between Traditional Chinese and English.

## GitHub Pages

In the repository settings, enable Pages with **Deploy from a branch**, select the default branch, and choose `/docs` as the folder. The published page will be available at the repository's GitHub Pages URL.
